## 🔥 Project Overview

**This tool** is a comprehensive trainer for **CICADAMATA"**. This trainer enhances CICADAMATA" runs with optional survivability, ammunition, movement, heat, timer, and score-practice features. ## 📖 Detailed Feature Guide

### Movement & Exploration

CICADAMATA" emphasizes momentum-based first-person traversal. Use jumps, dashes, stomps, and directional movement to cross open level spaces efficiently. Unlimited Movement is best used for learning routes, testing shortcuts, and recovering from missed jumps.

### Tools & Inventory

The game does not use a traditional inventory management system. The main collectible objective is retrieving cores during incursions. The trainer's ammunition option supports Joyeuse during combat, while Instant Core Collection assists with objective practice.

### World & Environment

Missions take place across freeform spheres within CASCADE. Enter a sphere, locate the required cores, deal with threats, and reach extraction. The timer and clearance systems encourage repeated runs and route optimization.

### Combat & Weapons

Combat is built around fast first-person encounters with hostile threats while maintaining movement. Use Joyeuse to clear enemies and preserve momentum. God Mode and One-Hit Threats are intended for learning enemy placement and practicing movement-combat transitions.
